# 02 — 接收后快速启动与核对

本页面向**接收技术团队**，说明在本机启动并核对交付物的最小步骤。

> 当前交付形态为本地运行形态；以下命令均基于仓库内既有工具链。正式公网
> 发布不在此列。

## 1. 环境要求

- 前端工具链：Node.js（仓库声明版本）与 pnpm（仓库声明版本）。
- 后端运行：Python（仓库声明版本）与本地 PostgreSQL 实例。
- 仓库内已提供依赖锁定文件；请勿手工逐个补装依赖。

## 2. 获取代码

以仓库管理员提供的代码仓库为准，检出交付分支并确认工作区干净。

## 3. 启动本地运行环境

本地运行由维护人员按仓库内运维说明（`docs/operations/`）执行，要点：

1. 准备 PostgreSQL，按运维说明创建数据库；
2. 安装后端依赖并在后端目录执行数据库迁移；
3. 安装前端依赖；
4. 分别启动后端服务与前端开发服务；
5. 通过浏览器访问前端地址。

> 若你是终端使用者而非维护人员：请直接使用维护人员提供的访问地址与
> 已授权账户，按《用户与学者操作指南》操作，无需自行启动环境。

## 4. 核对交付物（自检）

在仓库目录下可运行仓库既有命令完成核对：

| 核对项 | 命令（示意，以仓库实际为准） |
| --- | --- |
| 前端单元测试 | 在前端目录运行前端测试命令（仓库脚本 `test`） |
| 前端类型检查 | 前端类型检查命令（仓库脚本 `typecheck`） |
| 前端构建 | 前端构建命令（仓库脚本 `build`） |
| 后端测试 | 在后端目录使用项目虚拟环境运行测试 |
| 数据库迁移核对 | 按运维说明核对当前迁移版本 |

## 5. 建议的接收验收路径

按《用户与学者操作指南》逐条走查：

- 公共门户：打开首页 → 浏览八段内容 → 使用首页搜索 → 打开人物 →
  打开《针灸甲乙经》 → 打开非遗档案 → 搜索并查看无结果提示；
- 研究工作台：使用已授权研究账户登录 → 创建研究项目 → 列表回看 →
  创建笔记（可关联项目）→ 列表回看；刷新页面确认仍存在；
- 退出研究端并返回公共门户，确认权限边界符合预期。

如以上步骤有任一项无法在当前系统执行，说明该项尚未交付或需联系维护
人员确认环境，不要将其视为已可用的功能。

## 6. 遇到问题

参见《04 — 当前交付边界》与《用户与学者操作指南》常见问题；仍无法解决
时联系系统维护人员。
