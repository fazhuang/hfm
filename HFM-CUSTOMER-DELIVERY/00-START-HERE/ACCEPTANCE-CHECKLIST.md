# 00 — 验收清单（ACCEPTANCE CHECKLIST）

用法：按顺序执行，每项记录「通过 / 不通过 / 不适用（说明）」。公共功能
无需登录；研究功能需要**已授权研究账户**（由维护人员开通）。

## A. 环境与启动

- [ ] A1 按 `02-INSTALLATION/README.md` 完成安装、迁移与启动
- [ ] A2 健康检查通过：后端 `/health` 与 `/version` 返回 200 JSON
- [ ] A3 数据库迁移版本与说明一致（0014，单一迁移头）

## B. 公共门户（无需登录）

- [ ] B1 打开首页（`/`），页面正常渲染平台标题
- [ ] B2 首页八段内容按顺序可滚动浏览
- [ ] B3 首页搜索：输入「皇甫谧」回车 → 跳转搜索结果页并显示结果
- [ ] B4 人物页（`/persons/person-huangfu-mi`）可打开浏览
- [ ] B5 《针灸甲乙经》页（`/jiayi`）可打开浏览
- [ ] B6 非遗档案页（`/heritage`）可打开浏览
- [ ] B7 搜索无结果时显示「未找到匹配…的结果」并提供清除关键词
- [ ] B8 首页后台数据可用时参与呈现；不可用时不报错并可安全浏览

## C. 研究工作台（需已授权研究账户）

- [ ] C1 未登录访问研究页会被引导至登录页
- [ ] C2 使用研究账户登录成功并进入「研究工作台」
- [ ] C3 登录失败（错误密码）时提示失败
- [ ] C4 创建研究项目：点击「新增项目」→ 填写标题（必填）→ 「创建项目」
      → 提示「项目已创建」→ 列表可见
- [ ] C5 空标题被前端拦截并提示（不发起创建）
- [ ] C6 刷新页面后项目仍在（数据库持久化）
- [ ] C7 创建笔记：点击「新增笔记」→ 填写内容（必填，可选标题/关联项目）
      → 「创建笔记」→ 提示「笔记已创建」→ 列表可见
- [ ] C8 刷新页面后笔记仍在（数据库持久化）
- [ ] C9 普通访客/无研究权限账户不能进入研究端创建能力（权限边界成立）

## D. 边界与文档

- [ ] D1 `04-BOUNDARIES-AND-NEXT.md` 所列后续范围未出现在当前界面
- [ ] D2 交付包不含真实凭据/密码/密钥（内容扫描）
- [ ] D3 `NOTICE.md` 许可证事实披露准确

## 完成

- 全部通过（或「不适用」均有说明）→ 在交付方报告与验收记录中标注
  ACCEPTANCE=PASS。
- 任一「通过」项实际失败 → 记录现象与复现步骤，联系维护团队；不得将
  未执行项标记为通过。
