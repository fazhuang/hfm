# 03 — 已交付功能清单

以下功能均可在当前本地交付形态中实际操作；操作步骤见
《用户与学者操作指南》（docs/user-guide/HFM-USER-AND-SCHOLAR-GUIDE.md）。

## A. 公共门户（公众可访问）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| A1 | 首页八段内容 | 平台概览与检索、生平纪年、一部书、知识结构、史料证据、活态传承、研究导航、平台收尾 |
| A2 | 首页动态数据 | 首页读取后台公开数据；数据可用时参与页面展示，异常时自动回退已有内容 |
| A3 | 首页搜索 | 输入关键词跳转搜索结果页 |
| A4 | 人物档案 | 皇甫谧人物页面浏览 |
| A5 | 古籍相关页 | 《针灸甲乙经》相关内容、版本脉络与论著整理概貌 |
| A6 | 其言页 | 相关文言论著页面 |
| A7 | 非遗档案 | 皇甫谧针灸活态传承公开档案 |
| A8 | 全站检索 | 关键词检索、结果打开、无结果提示与清除关键词 |

## B. 研究工作台（经授权学者）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| B1 | 登录与鉴权 | 研究账户登录；未登录访问研究页面会被引导至登录 |
| B2 | 研究检索与浏览 | 高密度研究检索、实体与证据浏览 |
| B3 | 创建研究项目 | 填写项目标题（必填）与描述（选填）→ 创建 → 列表回看 |
| B4 | 项目持久保存 | 项目写入数据库，刷新后仍存在 |
| B5 | 创建项目笔记 | 填写笔记内容（必填）、标题与关联项目（选填）→ 创建 → 列表回看 |
| B6 | 笔记持久保存 | 笔记写入数据库，刷新后仍存在 |
| B7 | 查看与导出 | 查看项目/笔记；对研究内容进行文本或打印格式整理导出 |

## C. 数据与权限基线

- 内容遵循公开与授权的两级边界；普通访客不可创建研究内容。
- 学者可创建与维护自己的项目与笔记，不能访问管理后台功能。
- 管理/运营类功能不在本次交付范围（见《04》）。

## D. 本次交付后已补齐的关键闭环

- 研究工作台此前仅能浏览；本次交付使学者能够在浏览器中**创建研究项目与
  项目笔记**，并真实写入数据库后回看——「输入 → 保存 → 再次读取」的
  使用闭环已打通。
- 首页此前为纯静态展示；本次交付使首页**读取后台公开数据**并在数据可用
  时参与页面呈现，同时保留数据异常时的安全降级。
