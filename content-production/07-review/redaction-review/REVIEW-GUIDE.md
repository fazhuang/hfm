# 非遗材料审阅说明

> 这一页是给**做审阅的人**看的。不需要懂技术，不需要装任何软件。

---

## 你要做的事，一句话

**看一眼每张图，告诉我们这三件事之一：能直接公开、要先涂掉几处才能公开、还是不能公开。**

---

## 打开这两个地方

| 看什么 | 在哪 |
| :--- | :--- |
| **图**（84 张，56 件） | `content-production/07-review/redaction-review/pages/` |
| **表**（67 行） | `content-production/07-review/redaction-review/review-checklist.csv` |

用 Excel 或 Numbers 打开表格（UTF-8 编码）。用看图软件打开图。

**图和表怎么对上**：图的文件名来自表格里 `object_key` 那一列，规则是：

1. 去掉开头的 `非遗佐证/`
2. 空格、顿号、句点、斜杠等符号一律换成 `_`
3. 末尾加上 `__p页码.png`

```
表里：非遗佐证/02 领办人荣誉及获奖/1、平凉市名中医.pdf
图上：02_领办人荣誉及获奖_1_平凉市名中医_pdf__p1.png
      └ 去前缀、符号换 _ ─────────────────────────┘  └ p1 = 第 1 页
```

一件材料可能有好几页，就有好几个图，`__p1` `__p2` 依次排。

> **有 5 件的文件名过长，会被截短**（都是「刘君奇发表论文」和「2023结项证书」那几件长名字的）。对照时看开头一段能认出是哪件即可，**不影响坐标、也不影响脱敏**。

## 怎么读图上的坐标

每张图上都铺了**红色细线**和**红色数字**。

- 上方横排的数字 = 这个位置**距左边**多远
- 左侧竖排的数字 = 这个位置**距上边**多远

数字单位是「点」。**直接把图上读到的数字填进表格就行，不用换算。**

---

## 三种决定，填在 `review_decision` 这一列

| 填这个 | 什么时候填 |
| :--- | :--- |
| `publish_as_is` | 整张纸上**没有**需要遮挡的个人信息 → 直接公开 |
| `redact` | 有 → 按下面填坐标，我们先涂掉再公开 |
| `withhold` | 不适合公开 → 不公开，也不涂 |

---

## 什么算「需要遮挡」

**要遮：**

- 身份证号、出生年月日
- 电话号码、手机号、住址
- 证书编号
- 手写签名
- 银行账号

**不用遮**（这些本来就是可以公开的）：

- 姓名、单位名称、职务头衔
- 日期、公章
- 荣誉称号、项目名称

> 拿不准就填 `redact` 并把位置框出来。**多遮一处没关系，漏遮一处才是问题。**

---

## 要遮挡时，坐标怎么填

填在 `review_regions` 这一列。**一个区域写一段**，多段用**分号**隔开：

```
p1 120 300 400 340
```

```
p1 120 300 400 340; p1 100 500 300 540; p2 150 200 420 260
```

读法：`p页码` + 空格 + `左上角x 左上角y 右下角x 右下角y`

- `p1` = 第 1 页（对应 `__p1` 那张图）
- 前两个数字 = 要遮住的**左上角**
- 后两个数字 = 要遮住的**右下角**
- **数字之间用空格，不要用逗号** —— 表格是 CSV，逗号是列分隔符，写逗号会把后面的列挤错位

**框大一点没关系**，稍微超出实际内容不会出问题；框小了会漏。

## 表格怎么填：看两个例子

### 例子一：整张没有个人信息

平凉市名中医证书 —— 纸上是姓名、荣誉称号、两个颁发单位、日期、两枚公章。没有身份证号、没有电话、没有证书编号。

| object_key | review_decision | review_regions | reviewed_by | review_note |
| :--- | :--- | :--- | :--- | :--- |
| `非遗佐证/02 领办人荣誉及获奖/1、平凉市名中医.pdf` | `publish_as_is` | | 张×× | 仅姓名、单位、公章 |

### 例子二：有要遮的地方

假设某张证书右下角有证书编号，在图的横 380–560、纵 700–730 之间：

| object_key | review_decision | review_regions | reviewed_by | review_note |
| :--- | :--- | :--- | :--- | :--- |
| `非遗佐证/xx/xxx.pdf` | `redact` | `p1 380 700 560 730` | 张×× | 右下角证书编号 |

**`reviewed_by` 一定要填你的名字** —— 系统要求脱敏方案必须有具名的人审过，空着跑不了。

## 这几种不用你审

| 情况 | 件数 | 为什么 |
| :--- | ---: | :--- |
| 分级为 `P3` 的 | 4 | 政策规定**永不公开**，直接归档，不用看图 |
| `.docx` / `.doc` 文件 | 6 | 不按区域遮挡，走另一套流程 |
| `.jpg` 图片 | 1 | 没有坐标网格，单独处理 |

**其余 56 件、84 张图，就是你要过的全部。**

---

## 判不准怎么办

**填 `redact`，把位置框出来，在 `review_note` 里写一句你的疑问。**

比如：`p1 300 400 500 440` + 备注「这行看不清是不是身份证号，请复核」。

**不要因为拿不准就跳过。**空着的行，系统会当作没审过，整批都跑不了。

---

## 填完做什么

把表格存成 CSV，交给项目方。后面的步骤（生成脱敏方案、逐件涂掉、复核、发布）都由程序完成，不需要你再操作。

**原件不会被改动，也不会被公开** —— 涂掉的是另存的一份，原件始终保留、始终不公开。
