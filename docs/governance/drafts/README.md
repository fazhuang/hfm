# 治理修订草案（Drafts）

本目录存放**尚未生效**的治理修订草案。

## 这里的文件是什么

- **是什么**：给别人签署用的提案。逐字写明改哪一行、改成什么。
- **不是什么**：**不是治理文件**。目录里的任何内容都不生效，不构成授权，不改变任何断言的状态。

## 为什么单独放一个目录

`docs/governance/` 下的其余文件都是**已生效**的治理工件，其内容会被当作事实使用。草案混在里面，会被误读为已生效。放在 `drafts/` 子目录、且每个草案头部标明 `DRAFT · NOT IN FORCE`，可以把两者分开。

## 应用流程

草案经授权方签署后，由**有治理权限的一方**按草案的逐字补丁修改目标文件，并在**同一提交**内完成草案 §4 列出的代码与脚本同步 —— 否则登记册会指向不存在的节点。
