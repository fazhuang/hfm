## 2. 内容层架构

宪章 §4 已定：**门户 = 编辑型内容站**。落到执行，分三层：

```
①  静态叙事层   TS 内容文件        编辑可控，改内容 = 改文件 + 重建
    年表 · 简介 · 章节导览 · 文案

②  受控资产层   公开 API           实物资产，受 access_scope 约束
    82 PDF · 2 图 · 2 视频（转码后）

③  live 计数    公开 API           仅首页点缀：已发布著作 / 人物 / 术语
```

**为什么不能全静态**：96 件实物资产在数据库和对象存储里，不可硬编码。

**为什么不能全 live**：宪章要的是"专业排版与叙事"，顺序与措辞必须由编辑决定，数据库投影给不了。

**这条架构确立了门户前端的形态：叙事写死在内容文件里，实物走受控 API。** 现有的 G-10 困扰（4 个视图读静态数据）就此消解 —— 在编辑型门户里那是**正确做法**。

### 3.2 其言模块

**目标形态**：纯阅读页。排版是核心。

**前置**：原文来源已裁决（D-1，§9）—— **按公版录入**。四篇均为公版，来源已核实：

| 篇目 | 所据文献 |
| :--- | :--- |
| 《玄守论》 | 《晋书》卷五十一 · 列传第二十一 · 皇甫谧传 |
| 《释劝论》 | 同上 |
| 《笃终论》 | 同上 |
| 《三都赋》序 | 《文选》卷四十五 |

**录入规范**：

1. **底本用公版刻本**（四库全书本 / 武英殿本《晋书》），标点自行施加
2. **两源互校**，异文记录在案，不擅自择善
3. **页面标注所据**（如"据《晋书》卷五十一·皇甫谧传"），与门户"不做论证"不冲突 —— 标出处是诚实，不是论证
4. **不录入**十三篇存文中的其余各篇（超出宪章四模块范围，留作后续）

> 附注：皇甫谧今存文共十三篇，宪章四模块只取《玄守论》《释劝论》《笃终论》《三都赋》序四篇。其余九篇不在本期范围。

**技术方案（原文到位后）**：

| 要素 | 方案 |
| :--- | :--- |
| 版式 | 竖排 / 横排切换（CSS `writing-mode`，**零依赖**） |
| 字体 | `--hfm-font-ancient` **已存在** |
| 行距 | `--hfm-leading-reading` **已存在** |
| 字距 | `--hfm-tracking-ancient` **已存在** |
| 阅读宽度 | `--hfm-reader-max` **已存在** |

**排版系统的底子已经很厚** —— 六个字体角色、八级字号、阅读行距、古籍字距、阅读宽度，全部是现成 token。**这是门户最值钱的资产，其言页要用足。**

### 3.3 《针灸甲乙经》模块

**目标形态**：一书一页 —— 定本 → 版本谱系 → 结构导览。

| 段落 | 内容 | 件数 |
| :--- | :--- | ---: |
| 定本 | 这本书是什么、地位、结构 | 静态叙事（新写） |
| 版本谱系 | 版本脉络图 + 四个版本的影印 | 1 图 + **22 件公版影印** |
| 结构导览 | 12 卷 / 149 章 / 1007 段 | live |
| 影印翻阅 | 四库全书本 9 · 医统正脉 5 · 五车楼 4 · 行素草堂 4 | 22 件 PDF |

**影印翻阅的实现（零依赖）**：

```
<iframe src="/api/v1/public/media/{id}/bytes">   ← 浏览器原生 PDF 查看器
```

Chromium / Firefox / Safari 均原生支持，自带翻页、缩放、下载。**不引入 pdf.js。**

代价：移动端体验一般。**v1 接受**，桌面端是主要场景；移动端降级为封面 + 打开按钮。

> 515 篇论文与 70 本现代出版物按裁决移入研究平台，本模块因此更纯粹。

## 4. 排版系统

**结论：沿用现有 token，不新建体系。**

现有资产（`styles/tokens.css`，201 行）：

| 类别 | 已有 |
| :--- | :--- |
| 字体角色 | `--hfm-font-sans` / `serif` / `display` / `heading` / **`ancient`** / `numeric` |
| 字号 | `--hfm-text-xs` → `--hfm-text-4xl`（8 级） |
| 行距 | `tight` / `normal` / **`reading`** |
| 字距 | `display` / **`ancient`** |
| 间距 | `--hfm-space-0` → `-32`（13 级） |
| 阅读宽度 | **`--hfm-reader-max`** |
| 调色 | `--hfm-pr-*`（墨/暖/朱砂/青铜/石青/铜绿/靛） + `--wl-*`（纸/墨/线/标记） |

**要补的**：

1. **两个调色板并存**（`--hfm-pr-*` 与 `--wl-*`）需收敛为一套语义层，否则两套色系会在四模块间打架
2. 竖排支持：古籍竖排所需的最小补充（`writing-mode` 工具类与标点处理）
3. 非遗画廊的统一画框、比例、留白（宪章 §3.4 要求"陈列质量"）
