## 1. 定位与判据

**公众门户承担信息发布职能。**

> 一个编辑精良的专题网站，让一个完全不知道皇甫谧的人，在十分钟内知道他是谁、说过什么、写了什么书、留下了什么。

**唯一判据：浏览体验。**不是数据完整性，不是可核验性，不是可追溯性。

## 2. 三条设计原则

### 原则一：叙事优先于目录

每个模块是一个**讲清楚的故事**，不是资料列表。内容的顺序、措辞、配图由编辑决定，**不由数据库决定**。

### 原则二：排版是核心资产

文言文、古籍影印、书法图片、年表 —— 这些内容的呈现质量决定门户成败。字号、行距、留白、字体、图片裁切，是这一层的真功夫。

### 原则三：不做论证

页面上不摆证据链、不显示发布状态、不放数据来源角标、不做权威论证。**这是门户，不是论文。**

## 3. 四个模块规格

### 3.1 皇甫谧其人

**任务**：三分钟回答"他是谁、为什么重要"。

| 层 | 内容 | 素材 |
| :--- | :--- | :--- |
| 定位 | 一句话：西晋医学家、文学家、史学家，针灸学宗师 | 现有 |
| 年表 | 生平四阶段：少家贫 → 屡征不仕 → 中年风痹 → 晚年著书 | 现有 |
| 画像 | 皇甫谧画像 | 1 件 |
| 影像 | 《针灸鼻祖皇甫谧》纪录片 | 2 件 |
| 文字 | 其传、后论 | 2 件 |

**形态**：长页叙事 + 年表交互。

**明确不做**：23 条断言与证据的展示。那是研究平台的资料。

### 3.2 其言

**任务**：让人**读得到**皇甫谧自己的文字。

内容：三都赋、玄守论、释劝论、笃终论。

**形态**：纯阅读页。这是最考验排版、也最容易做坏的一页，必须解决四件事：

- 竖排 / 横排的选择与切换
- 生僻字处理（注音、释义）
- 注释位置（夹注 / 页边 / 悬浮）
- 阅读进度与篇章导航

**这一页做好了，门户就立住了。**

### 3.3 《针灸甲乙经》

**任务**：讲清"这是一本什么书"，并让版本**看得见**。

| 内容 | 件数 | 形态 |
| :--- | ---: | :--- |
| 公版原刻影印（明万历 / 清乾隆 / 清光绪） | 22 | **可翻阅的影印本** |
| 版本脉络图 | 1 | 大图 + 版本演进叙事 |
| 篇章结构（12 卷 / 149 章 / 1007 段） | — | 结构浏览 |

**形态**：一书一页 —— 定本 → 版本谱系 → 结构导览。

**关键体验：影印本翻页。** 22 件原刻影印是本模块最有价值的资产，让公众看到明万历吴勉学的真刻本。做不好等于没有。

> 注：515 篇现代研究论文与 70 本现代出版物已按裁决移入研究平台。本模块因此更纯粹，也更适合公众。

### 3.4 非遗传承

**任务**：展示活态传承的**成果**。

| 内容 | 件数 |
| :--- | ---: |
| 证书与资质（脱敏后） | 67 |
| 传承人 | 2 位 |
| 传承项目与关系 | 56 |

**形态**：陈列式，接近画廊。四个模块中"展示"属性最强，最不需要叙事技巧，最需要**陈列质量**：统一画框、统一比例、统一留白。

**这一模块的价值**：它是全部门户里**唯一有"当代活人"的部分**。前三个模块都通向历史，只有这里通向现在。

## 4. 技术形态

**门户 = 编辑型内容站，不是数据库投影站。**

理由：排版与叙事要求编辑控制顺序、措辞、配图，数据库投影给不了这个。且门户的 96 件展示资料稳定，不频繁变动。

**保留的 live 部分仅限**：首页的少量统计计数（已发布著作 / 人物 / 术语）。这类数字让页面"活"，但不承载叙事。

**推论**：门户前端不需要复杂的数据层。"某视图读静态数据而非 live 端点"在编辑型门户里是**常态，不是缺陷**。

- [ ] 四个模块各一页，内容完整，**无占位文字**

- [ ] 非遗页陈列脱敏后的传承成果
- [ ] 全站在 375 / 768 / 1440 三档无横向溢出
- [ ] 单页文案无错字、无未完成的标点
- [ ] 页面上**没有**任何证据链、发布状态、数据来源标记
- [ ] 公开 API 只暴露本宪章第 5 节的资料，不暴露研究资料

## 7. 明确不做

| 不做 | 原因 |
| :--- | :--- |
| 数据对比、分析、权威论证 | 建设目标明确排除 |
| 证据链、断言、引文的公众展示 | 属研究平台 |
| 临床诊疗内容 | CR-005 医学边界 |
| 3D / VR / XR | CR-018/019/020 已延期 |
| 复杂的数据可视化 | 信息发布不需要 |
| 任何 AI 生成内容 | 门户不做论证，也不做生成 |
