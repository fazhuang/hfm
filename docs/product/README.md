- **是什么**：建设目标的正式记录。后续每一份执行规划、每一个工作包，都以对应宪章为验收基准。

## 共同前提

两份宪章建立在同一次建设目标纠正之上（2026-09-15）：

- 项目 = 公众门户 + 研究平台两个版块；
- 公众门户承担**信息发布**职能，四个模块：皇甫谧其人 / 其言 / 《针灸甲乙经》/ 非遗传承；其核心是**专业排版与组织形式**，让公众通过浏览直观快速了解；**不做**数据对比、分析、权威论证；
- **研究平台是本项目的核心**，供研究者（教授、学生、爱好者）访问并操作平台进行人文学术研究。
