# 皇甫谧人文数字平台 — 用户与学者操作指南

本指南面向两类使用者：

- **公众 / 普通访客**：浏览人物资料、古籍文献、非遗传承与检索公开内容。
- **学者 / 研究工作台用户**：登录后创建研究项目、记录考证笔记并回看内容。

本指南描述的每一步都基于当前已交付并可实际操作的系统界面编写；凡当前
尚未开放的能力，均不写成可执行功能，并在「当前交付边界」中说明。

---

## 1. 平台简介

皇甫谧人文数字平台围绕西晋医学家、文学家皇甫谧及其著作（以《针灸甲乙经》
为代表）建立数字人文资料与公开浏览服务。

当前系统由两部分组成：

- **公共门户**：任何访客都可以浏览的平台首页、人物资料、《针灸甲乙经》
  相关古籍内容、非遗活态传承以及全站检索。
- **研究工作台**：经授权的学者登录后使用的研究环境，可检索研究内容、
  创建研究项目并为项目记录考证笔记。

本指南使用「皇甫谧人文数字平台」指代产品；页面具体文案以界面实际显示
为准。

## 4. 首页

首页采用八段纵向结构：平台概览与检索（Hero）、皇甫谧生平纪年、一部书
（《针灸甲乙经》）、知识对象结构、史料证据、活态传承、研究导航入口与
平台收尾说明。

### 首页搜索如何使用

1. 在首页顶部的「检索平台内容」搜索框中输入关键词（例如「皇甫谧」）。
2. 按回车或点击「检索」按钮。
3. 页面会跳转到搜索结果页并展示匹配结果。

### 页面内容是如何显示的

首页会优先呈现经过整理的平台介绍内容；在系统数据可用时，部分栏目的
公开内容数量等信息会随数据自动更新。若数据服务暂时不可用，首页会安全地
显示已有内容，不影响正常浏览——不需要你做任何操作。

## 5. 人物资料

1. 从首页「进入人物档案」或顶部导航进入「人物（皇甫谧）」。
2. 页面展示皇甫谧的核心信息与相关整理内容。
3. 通过页面上的相关链接可以继续浏览关联内容。

当前人物页面为浏览与阅读功能，不提供编辑入口。

## 8. 搜索

### 在哪里搜索

- 首页搜索框（平台内容检索）。
- 搜索结果页顶部的搜索框。

### 如何搜索

1. 在搜索框输入关键词，例如人物名「皇甫谧」、作品名「甲乙经」等。
2. 按回车或点击「检索」。
3. 结果按条目展示；点击结果条目可进入对应内容页面。

### 没有结果时

如果没有匹配内容，页面会显示「未找到匹配「…」的结果」，并提示可以尝试
的关键词类型，同时提供「清除关键词」操作。

## 9. 研究工作台

研究工作台是供**已授权学者**使用的环境。只有持有研究账户并通过验证的
用户才能进入；普通访客无法访问，未登录访问会被引导到登录页。

### 9.1 进入与登录

1. 在登录页输入研究账户的用户名与密码。
2. 点击「登录」。
3. 登录成功后进入「研究工作台」；之后访问研究相关页面时保持登录状态。
4. 如要退出或返回公共门户，使用页面提供的相应操作。

> 登录失败时页面会提示「登录失败」；请检查用户名与密码，或联系系统维护
> 人员确认账户是否已授权。请不要在公共或共享设备上保存密码。

### 9.2 创建研究项目

研究项目用于组织一段独立的研究主题。

1. 进入「研究工作台」。
2. 在「我的研究 → 研究项目」区域点击「新增项目」。
3. 填写：
   - **项目标题**（必填，例如「《针灸甲乙经》版本源流考」）；
   - **项目描述**（选填，可写一段研究说明）。
4. 点击「创建项目」。
5. 创建成功后页面提示「项目已创建」，新项目会立即出现在「研究项目」
   列表中。

**如何确认项目已保存**：创建后项目出现在列表中即为已保存；刷新页面后
项目仍然存在。

### 9.3 创建项目笔记

笔记用于记录一段考证或阅读心得，可挂在某个项目下，也可不关联项目。

1. 在「我的研究 → 我的笔记」区域点击「新增笔记」。
2. 填写：
   - **笔记标题**（选填）；
   - **关联项目**（仅当你有项目且需要关联时选择；也可留空）；
   - **笔记内容**（必填）。
3. 点击「创建笔记」。
4. 创建成功后页面提示「笔记已创建」，新笔记会立即出现在「我的笔记」
   列表中。

**关于持久保存**：笔记提交后写入数据库并真实保存；刷新页面后仍能读取。

### 9.4 查看与读取

- 在「研究项目」与「我的笔记」列表中可查看已创建的项目标题、描述、笔记
  标题与内容概要，并看到对应的记录标识。
- 研究工作台同时提供研究内容检索、实体浏览与导出功能（导出用于将研究
  内容整理为文本或打印格式）。

> 说明：当前交付范围支持**新增项目与笔记**；本指南不包含笔记编辑流程。
> 若需要编辑能力，请联系系统维护人员确认后续安排。

## 12. 常见问题

### 页面打不开 / 页面空白

- **现象**：浏览器无法打开首页或内容区为空。
- **你可检查**：网络是否正常；是否使用了正确的本地地址。
- **何时联系维护人员**：页面长期空白或报错，请截图并联系维护人员。

### 首页内容暂时不更新 / 数据服务不可用

- **现象**：首页仍能浏览，但动态数据栏目标识为不可用或保持不变。
- **你可检查**：稍等片刻后刷新页面；这通常是后台数据服务暂时不可用，
  系统会自动回退到已有内容，不影响浏览。
- **何时联系维护人员**：长时间未恢复，可联系维护人员检查数据服务。

### 登录失败

- **现象**：输入用户名与密码后提示登录失败。
- **你可检查**：用户名与密码是否输入正确；账户是否已由维护人员授权。
- **何时联系维护人员**：确认无误仍无法登录，请联系维护人员。

### 提示没有研究权限 / 无法进入研究工作台

- **现象**：访问研究页面被引导到登录页或提示无权限。
- **说明**：研究工作台仅向已授权研究账户开放。
- **何时联系维护人员**：你确认为研究账户但仍无法进入，请联系维护人员。

### 提交项目 / 笔记失败

- **现象**：点击「创建项目」或「创建笔记」后提示失败。
- **你可检查**：必填字段是否已填写完整（项目标题、笔记内容）。
- **何时联系维护人员**：字段完整仍提交失败，说明后台保存服务可能异常，
  请稍后重试或联系维护人员。

### 搜索无结果

- **现象**：输入关键词后显示「未找到匹配…的结果」。
- **你可检查**：换用更常见的关键词，如「皇甫谧」「甲乙经」。
- **何时联系维护人员**：对明显存在的内容也搜索不到时，可联系维护人员。
