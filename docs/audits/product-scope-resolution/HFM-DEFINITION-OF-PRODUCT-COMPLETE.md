# HFM-DEFINITION-OF-PRODUCT-COMPLETE.md — 产品完成定义与多维验收准则 (DoD)

禁止以后使用模糊单一的 `COMPLETE` 概念，必须分三个不同层次进行独立定义与核验：

---

## 1. 软件工程完成定义 (SOFTWARE_COMPLETE)

只有当以下条件全部达成时，方可裁决 `SOFTWARE_COMPLETE = YES`：
1. **公众端门户 8 大核心页面全部实现且可正常交互**（首页、人物、作品、甲乙经、非遗、读者、检索、媒体库）。
2. **研究工作台具备读写闭环**：除了当前的只读检索与成果导出外，前端具备学者在线创建研究项目与考证笔记的表单 UI，并与后端对应 API 联通。
3. **首页具备后端 API 联通与优雅降级**：调用 `/api/v1/public/home` 并在网络/后端离线时平滑回退至本地静态数据。
4. **后端 50+ 个 API 路由、5 级 RBAC 权限与数据模型测试全绿**（Pytest 100% Pass）。
5. **前端无类型错误，构建产物零异常**（Vue-tsc 与 Vitest 100% Pass）。
6. **自动化运维与发布脚本齐备**（具备生产环境检测器、单管理员初始化脚本、打包发布脚本）。

---

## 2. 内容建设完成定义 (CONTENT_COMPLETE)

只有当以下数据工程全部达成时，方可裁决 `CONTENT_COMPLETE = YES`：
1. **《针灸甲乙经》349 穴位全部录入**：包括穴位名称、经络归属、古代与现代定位、主治病候。
2. **全书 12 卷 128 篇经文条文全量数字化校勘录入**。
3. **515 篇当代研究论文全部建立结构化题录与检索索引**。
4. **多媒体高精影印图像资产全部挂接**。

---

## 3. 最终客户交付完成定义 (FINAL_CUSTOMER_DELIVERY_COMPLETE)

当且仅当满足：
1. `SOFTWARE_COMPLETE = YES`；
2. 系统包含满足 `HFM-MINIMUM-DELIVERY-DATASET.md` 规定的最低可运行数据集（所有界面无死链、空白）；
3. 交付完整的《系统本地部署与运维手册》与《用户与学者操作指南》；
4. 通过 `GATE-A` 与 `GATE-B` 双重发布验收；
5. 在客户指定的物理/云端生产环境中部署并冒烟通过。
