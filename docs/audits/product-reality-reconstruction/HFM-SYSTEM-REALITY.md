## 1. HFM 当前到底是什么

**皇甫谧人文数字平台（HFM）** 是一套面向文史哲、中医学者与社会公众的**高品质数字人文学术基础设施与典籍门户**。

平台以魏晋著名学者、针灸学奠基人**皇甫谧**为旗舰核心，通过数字化手段深度重构其一生轨迹、传世核心典籍《针灸甲乙经》版本源流、历史典籍评价与名家引文考据、以及当代活态针灸非遗传承脉络。

系统在底层建立了严密的学术证据链条与安全可信的数字档案库，既能为大众读者提供沉浸式、高可读性的文史浏览体验，也能为专业学者提供分面学术检索、证据图谱溯源与结构化成果导出的研究环境。

## 2. 当前用户在系统中能做什么

### 2.1 公众读者（无需登录）
- **全景宏观概览**：在平台首页连续浏览八大板块，全方位了解皇甫谧的“一生、一部书、知识对象、史料证据与活态传承”。
- **学术生平考据**：查看皇甫谧 215—282 年的生卒年学术定论、四阶段人生历程、重要纪事年表与名家评价。
- **《针灸甲乙经》版本检索**：查阅宋本、元本及现代校注本源流，浏览全书 12 卷 128 篇的完整篇名与结构。
- **古籍原文阅读**：在文献阅读器中查阅精选古籍文本（如名家撰写的后论、其传），点击句子查看对应出处与引用卡片。
- **活态非遗了解**：查阅国家级非遗项目“皇甫谧针灸术”的传承脉络，详细查阅以第六代传人刘君奇为代表的名医档案。
- **全站学术搜索**：在搜索框输入任意学者、作品、穴位或概念，按人物、作品、版本、文献、非遗分类筛选，并高亮匹配内容。
- **数字多媒体浏览**：在媒体资料库中查看古籍影印、石碑画卷等高清数字化图像资产。

### 2.2 专业研究人员（登录学者账号）
- **进入专属研究工作台**：通过严格的角色与密码校验后进入 `/research` 鉴权空间。
- **查阅高密度学术元数据**：查看当前平台可供研究的实物盘点，包括古籍、论著、论文统计指标。
- **学术级深度检索与证据追溯**：使用专属检索界面，查看实体属性、关联证据链与引用考据卡片。
- **一键学术成果导出**：在导出面板中将检索或考据结果一键生成标准 Markdown 文件，或直接生成排版优良的纸质打印视图。
- *(注：学者自建研究项目与个人笔记的后台 API 与数据库均已就绪，当前网页端暂未开放输入表单)*。

### 2.3 系统管理员（登录管理员账号）
- **安全审计日志**：进入 `/admin/audit` 查看全站用户操作流水、时间戳、操作人与敏感行为审计记录。
- **数据一致性对账**：一键触发跨实体、引文与版本数据一致性对账引擎，确保没有孤立或死链学术数据。

## 6. 前端如何运行

```text
 用户浏览器
     │
     ▼
 Vue 3 核心单页框架 (Single Page App)
     │
     ▼
 Vue Router (前端路由网关)
   ├── 公共公开路由 (/persons, /jiayi, /search 等) ──► 加载对应 View 视图组件
   └── 鉴权受限路由 (/research, /admin) ──────────────► 经过 guards.ts 角色校验 ──► 加载对应视图
     │
     ▼
 视图数据装配机制 (Data Flow)
   ├── 优先向后端 API 发起异步 HTTP 请求 (通过 /services/api.ts)
   └── 若网络异常或数据未导入，自动触发内置的高保真 Projection 静态知识集进行平滑降级
```

## 7. 后端如何运行

```text
 客户端 HTTP 请求 (端口 8000)
     │
     ▼
 FastAPI 应用框架 (main.py)
     │
     ▼
 全局安全中间件 (RequestID 追踪 + 统一异常处理器)
     │
     ▼
 接口命名空间分发 (API Routers: Auth / Public / Research / Admin)
     │
     ▼
 服务端严格鉴权 (Dependency Injection: 校验 Bearer Token 与 5 级 RBAC 权限)
     │
     ▼
 领域服务层 (Domain Services: Person, Literature, Search, Research 等)
     │
     ▼
 数据访问仓储层 (Repositories & SQLAlchemy Async ORM)
     │
     ▼
 PostgreSQL 关系数据库 (通过 Alembic 迁移脚本严格保障 Schema 一致性)
```

## 8. 数据如何流动

### 读流程（公众查阅）
```text
数据库 (PostgreSQL)
  └─► 后端 Service 查询已审核发布数据 (PUBLISHED 强约束)
        └─► 转换为公开安全 DTO JSON
              └─► 前端 API Client 接收
                    └─► Vue 响应式状态
                          └─► 呈现在屏幕上
```

### 写流程（学者研究 —— 当前后端能力）
```text
学者发起操作
  └─► 携带 JWT 身份凭证
        └─► 后端 RBAC 校验权限是否匹配
              └─► 强行注入当前真实用户 ID 作为 owner_id (杜绝数据篡改与越权)
                    └─► 写入 PostgreSQL (research_projects / notes)
                          └─► 记录 AuditLog 审计日志
```

## 9. 当前系统需要哪些服务与环境

1. **前端静态资源托管服务**：如 Nginx，用于向浏览器分发 HTML、JS 与 CSS，并将 `/api` 流量反向代理至后端。
2. **后端 API 运行进程**：Python 3.13 驱动的 Uvicorn / FastAPI 服务进程。
3. **关系型数据库**：PostgreSQL 15+（生产环境），本地或单机环境支持一键 SQLite 快速运行。
4. **数字多媒体持久化目录**：本地存储卷，用于存放古籍扫描件、影印插图等静态图片。

## 10. 当前系统最终会交付什么

1. **面向社会的“皇甫谧人文数字学术门户”**：一套开箱即用、视觉典雅、经过严格无障碍和多设备测试的上线系统。
2. **面向机构的“数字人文基础架构资产”**：包括完备的 28 个核心数据表模型、标准化的 RESTful API 接口、生产环境自动化配置与一键构建工具。
3. **可信赖的测试与验证资产**：近千项实测通过的自动化单元测试与集成测试套件，确保未来任何功能迭代均不破坏现有学术资产。
