# HFM-GAP-MAP.md — 影响交付的产品与工程缺口全景图

本清单剔除所有理论性假设，仅列出真实影响客户交付与体验的缺口。

---

## P0 — 阻断系统正确运行或交付 (当前：0 项)

- **无**。当前代码在本地运行、编译构建、前后端通信、自动化测试套件（960+ 用例）中均完全畅通，不存在系统级阻塞性故障。

---

## P1 — 重要产品能力缺失 (当前：2 项)

1. **研究工作台在线编辑/写操作表单缺失** (`GAP-01`)
   - **现状**：后端具备完善的 `POST/PATCH/DELETE /api/v1/research/projects` 和 `notes` 接口与所有者数据隔离，但前端仅有只读浏览页面 (`ResearchHomeView.vue`)，没有“新建研究项目”、“编辑笔记”的界面表单。
   - **影响**：学者无法在 Web 页面上直接沉淀个性化研究笔记，当前工作台更偏向“高级只读考据看板”。

2. **首页数据尚未完全打通后端动态接口** (`GAP-02`)
   - **现状**：前端首页 8 个 Section 均采用本地静态 Projection (`homeProjection.ts`) 渲染，没有接入后端 `/api/v1/public/home` 接口。
   - **影响**：若运营人员在数据库中修改了学术数据，无法直接反映在首页，需要重新编译前端发布。

---

## P2 — 质量/数据完善项 (当前：3 项)

1. **当代研究论文全文与检索覆盖率有限** (`GAP-03`)
   - **现状**：文献库审计记录有 515 篇论文，但当前结构化建立检索索引的仅为精选的 10 篇代表论文。
   - **影响**：用户检索论文时命中范围较窄。

2. **《针灸甲乙经》349 穴位与全本条文深加工待填充** (`GAP-04`)
   - **现状**：卷篇骨架、版本考据及经典篇目（后论、其传）已高质量呈现，但 349 个穴位的现代定位与全本经文未完全数字化入库。

3. **管理端内容审核与媒体上传 UI 缺失** (`GAP-05`, `GAP-06`)
   - **现状**：后端支持论文/成果提交流程以及媒体上传，但前端 Admin 界面仅有审计日志与对账视图，缺少可视化的成果审批工作流与文件上传面板。

---

## P3 — 后续增强项 (交付后演进)

1. **用户操作指南手册**：编撰面向普通读者与学者的图文手册。
2. **移动端手势与深度适配优化**。
3. **知识图谱三维交互可视化**。
