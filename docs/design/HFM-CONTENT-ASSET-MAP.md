## 0. 审阅结论（一段话）

客户材料目录结构与 5 链接导航**完全同构**：

- `hfmzl/皇甫谧/`（其传/其言/后论/电影）→ 导航「人物（皇甫谧）」「其言」的内容源；
- `hfmzl/针灸甲乙经/`（版本脉络/论著/论文）→ 导航「《针灸甲乙经》」的内容源；
- `zzcl/`（传承人申报档案，领办人**刘君奇**：皇甫谧针灸市级非遗代表性传承人、皇甫谧针灸学院院长）→ 导航「皇甫谧针灸非遗的传承」之「传承人物（重点第六代名医）」的核心内容源。

因此 UI 方案的主要调整是：**传承区不再是"谱系图 + 空态"，而是可建成有真实内容的「传承人物档案页 + 证书展墙 + 媒体报道 + 工作室与师承」页面**；甲乙经区论著/论文有 600+ 件真实资产可排布；同时两类材料都存在**权利/隐私分级**问题，公开呈现前必须逐件裁决。

## 3. 展示策略（客户授权 + 隐私模型，取代原版权分级）

**客户正式授权（2026-09-01）**：客户提供资料统一视为已获授权、允许全部公开发布（`CUSTOMER_PROVIDED = TRUE` → `PUBLICATION_AUTHORIZATION = GRANTED`）。版权不作为开发约束。完整政策见 `HFM-ASSET-PRESENTATION-POLICY.md`。

原版权分级（RIGHTS_CLASS / R0–R3 / fail-closed）对客户提供材料**不再适用**（标记 `NOT_REQUIRED_FOR_CUSTOMER_PROVIDED_ASSETS`）。保留的是**隐私维度**（独立于版权）：

| 级 | 定义 | 适用资产（zzcl/hfmzl） | UI 行为 |
| --- | --- | --- | --- |
| P0/P1 | 公开内容 / 职业·学术·公共身份 | 其传/其言/后论文本、版本脉络图、论著/论文题录、公开荣誉与兼职 | 正常公开 |
| P2 | 需脱敏的个人信息 | 证书编号/签字、联系方式、名单、身份证明 | 生成 public derivative（脱敏）后公开；**不因单字段废弃整份材料** |
| P3 | 不应公共展示的敏感信息 | 法人证照原件、考评员名单、不动产证明、内部申报表 | 不进入公共投影；仅归档/按 RBAC 受限 |

**UI 实现要求**：公共端 P2 级资产消费脱敏后的 public derivative；P3 级不设公共入口；无版权状态导致的 fail-closed（内容未准入时以 empty state 呈现，见 HFM-UI-CONTENT-MODEL §8）。
