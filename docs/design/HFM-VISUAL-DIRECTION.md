## 1. 方向裁定的经过

`HFM-UI-CK.PNG` 给出六个候选方案，各自一行关键词：

| 方案 | 关键词 | 判定 |
| :--- | :--- | :--- |
| 一 · 东方人文 · 雅致留白 | 文化感 / 克制 / 学术 / 现代东方 | 近似 v1 的浅色纸面方向。**未采用** |
| 二 · 数字科技 · 知识图谱 | 科技感 / 数据可视化 / 专业 / 现代 | 偏工具端，公众门户过冷。**未采用** |
| 三 · 地域文化 · 山水人文 | 地域特色 / 人文叙事 / 大气 / 文化自信 | 把平台绑在灵台一地，与"国家级平台"定位不符。**未采用** |
| 四 · 典籍文献 · 书卷气质 | 文献质感 / 信息层级 / 沉稳 / 学术 | 适合典籍栏目，不足以承载首页。**未采用** |
| 五 · 现代简约 · 思想与人物 | 简洁 / 思想表达 / 现代感 / 高级 | 克制但无场馆感。**未采用** |
| **六 · 沉浸体验 · 未来展厅** | 沉浸感 / 互动体验 / 文化科技融合 / **面向公众** | **采用** |

**采用理由**：门户的唯一判据是浏览体验（`HFM-PUBLIC-PORTAL-CHARTER-v1.md` §1）。方案六是六者中唯一把"影像优先"作为结构前提的方案——它用真实影像承担首屏与段落骨架，其余五案都以文字与留白承担。客户材料里有雕像、展厅、古籍书叶、实拍照片，正好落在这一方向上。

## 2. 视觉系统

### 2.1 画布与材质

- **深色画布**。近黑但偏墨绿（`#0f1211` 级），**不是纯黑**——纯黑会让古籍书叶的暖黄显得脏。
- 三个层级：画布（页面底）→ 抬起面（卡片 / 行）→ 展板面（资料面板、玻璃展板）。
- 材质语言是**玻璃与灯箱**，不是纸张。古籍影像浮在暗场里，像展柜中的打光展品。

### 2.2 光

光**从上方来**，极弱顶光只用于建立方向感，不做装饰性光效。
阴影极少使用；层次由亮度差与发丝线建立，不由投影建立。

### 2.3 强调色

**全站只有一个强调色：青铜。** 用于刻度、序号、当前导航项、细线强调。

这是方案六最硬的一条约束。旧方向里同时存在朱砂（交互）与铜金（非遗）两个强调色，展厅方向下二者合并为青铜一个——**强调色一多，暗场里立刻变成杂色**。

### 2.4 分隔

- 段与段之间：**大留白** + 极弱发丝线。
- 段内元素之间：发丝线。
- **不用卡片投影分栏，不用圆角块分栏。**

### 2.5 字体

沿用现有六个字体角色，不新建：

| 角色 | 用途 |
| :--- | :--- |
| `display` / `heading` / `serif` | 中文标题与正文（宋体系） |
| `ancient` | 古籍引文、竖排文本 |
| `sans` | 界面控件、说明文字 |
| `numeric` | 数字指标 |

字号八级（`--hfm-text-xs` → `-4xl`，12 → 56px）已存在，够用。

### 2.6 中英并置

每个段落带一个**英文小标**，置于中文标题上方或下方，字号小、字距宽、颜色弱：

```
人物
PEOPLE

皇甫谧与《针灸甲乙经》
HUANGFU MI AND THE CLASSICS
```

这不是装饰，是参考图的固定节奏——它给每一段一个"展签"式的开头。全站统一，不得时有时无。

### 2.7 影像

- **全站真实影像**：客户提供的雕像照、展厅照、古籍书叶扫描、实拍照片、转码后的纪录片截帧。
- 不用插画、不用图库占位图、不用生成图。
- 影像承担**结构**职责（首屏整幅、段落主图、卡片配图），不只承担装饰。
- 每张影像有语义化的 `alt`；纯装饰层 `alt=""`。

### 2.8 引文卡

参考图每一屏都有一处竖排或右侧引文卡：引文 + 出处署名。这是本方向的签名元素之一，用于让古代文本在深场里发声。
