## 1. 方向研究（五类候选评估）

| 方向 | 定义 | 适合 HFM 之处 | 风险 | 与 HFM 契合度 |
| --- | --- | --- | --- | --- |
| 1. Museum Editorial（博物馆式编辑设计） | 大留白、宽网格、策展式首页、物件+说明牌式信息卡、克制的深色/中性画布 | 契合"文化展示 + 参观者优先"（CR-004）；适合 HERO/WORKS/史料馆 | 过度装饰会偏离"学术可信" | ★★★★★ |
| 2. Digital Archive（数字档案馆设计） | 数据优先、元数据可见、列表/表格密度高、搜索/过滤为核心 | 契合"权威数字人文资料 + 证据可见"（P8）；适合文献典籍/检索/版本 | 单独使用会变成"功能菜单集合"，无叙事 | ★★★★☆ |
| 3. Academic Publishing（学术出版物设计） | 期刊/专著式排版、衬线标题、脚注/引用体系、克制配色 | 契合"学术出版 + 长文阅读"（P6）；适合 Reader/人物页 | 单独使用缺乏文化温度 | ★★★★☆ |
| 4. Digital Humanities（数字人文研究界面） | 实体网络图、时间轴、文本挖掘视图、工具性 UI | 契合"知识探索 + 研究台"（P7/P9） | 工具感强，不适合纯公众页 | ★★★★☆（研究端） |
| 5. Cultural Institution（高等级文化机构视觉） | 机构徽记、严谨网格、低调奢华、印刷级排版 | 契合"权威 + 政校共建"（P2） | 容易滑向"政府门户"或"宫廷风" | ★★★☆☆ |

### 结论

单一方向均不完整。HFM 采用**混合方向**，主次明确（UI-00 v2 正式收敛为 `CONTEMPORARY CHINESE DIGITAL HUMANITIES / 当代东方数字人文`）：

> **"东方书籍文化 × 现代博物馆 × 学术出版 × 数字档案"**
> 以 **Museum Editorial（策展叙事）** 为公共门户骨架，
> 以 **Academic Publishing（学术排版）** 承载阅读与人物，
> 以 **Digital Archive / Digital Humanities（密度与工具）** 承载检索与研究端，
> 以克制的 **Cultural Institution 气质**（严谨网格、机构署名）兜底权威感。

**明确排除**：仿古网站 / 中医养生馆 / 国潮电商 / 政府红模板 / 高校蓝模板 / SaaS Dashboard / 大量卷轴 / 宣纸背景泛滥 / 祥云回纹装饰泛滥 / 廉价水墨 / 金龙宫廷风（P3）。

颜色语义方向（本阶段确定 semantic direction，**暂不冻结最终 HEX**）：暖白 / 墨色 / 低饱和朱砂 / 土褐 / 铜金 / 青灰（见 HFM-DESIGN-TOKENS-PROPOSAL）。

而**不是**"传统中医网站"（P3 排除）。

## 2. 统一视觉方向陈述

**方向名（UI-00 v2 正式）**：`CONTEMPORARY CHINESE DIGITAL HUMANITIES / 当代东方数字人文`

**核心气质（P4 定义）**：典雅 · 克制 · 权威 · 可考（+ 安静 · 现代）

**一句话**：一座让参观者愿意停留、让研究者信任、让古籍读起来舒服的**数字人文档案馆**——像当代博物馆的展厅墙与学术出版物的版面，而不是网页化的宣传册。

**三层气质分置**（同一 token 体系内）：

| 面 | 气质主导 | 表达 |
| --- | --- | --- |
| 公共门户（T1） | Museum Editorial | 大留白、策展式分区、说明牌式卡片、影像优先 |
| 阅读/人物（T2） | Academic Publishing | 衬线正文、受控列宽、脚注式出处、时间轴 |
| 研究端（T3） | Digital Archive + DH | 高密度表格/列表、facets、证据链、无装饰效率优先 |

## 3. 视觉词汇（Do / Don't）

### 3.1 色彩气质

| ✅ 方向 | ❌ 避免 |
| --- | --- |
| 暖白/米白画布（存档纸色，非"做旧宣纸"） | 大红+金色的"中国文化=红金"公式 |
| 墨黑/深灰为正文主导 | 高饱和朱红大面积使用 |
| 低饱和朱砂作唯一强调（印章式） | 紫/蓝 SaaS accent（现 `#7c3aed`） |
| 铜金/暗金作 heritage 级点缀（分隔线、徽记、年份数字） | 金碧辉煌装饰 |
| 青灰作次要信息/元数据 | 多种强调色并存 |

规则：**每屏一个强调色源**（heritage accent），其余为中性；证据/引用/版本用语义色而非装饰色（P8）。

### 3.2 排版气质

| ✅ | ❌ |
| --- | --- |
| 中文衬线（宋体系）用于标题/古籍正文（系统字体栈，见 Token 提案） | 全部内容使用系统无衬线（现状） |
| 无衬线用于 UI/元数据/数据 | 装饰性书法字体（授权/性能/可读性风险） |
| 竖排题名仅作克制点睛（低频，如封面/扉页） | 正文竖排（阅读障碍） |
| 大字标题 + 留白形成层级 | 用颜色堆叠制造层级 |

### 3.3 空间与层级

- 统一 spacing scale（4px 基），页面节奏 = 大留白分区 + 细边框分层。
- 层级主要靠 **留白 + 字重 + 字号 + 细线**，不靠阴影/悬浮（P4）。

### 3.4 边框 / 分隔线 / 卡片

| ✅ | ❌ |
| --- | --- |
| 1px 细边框 + 大圆角克制（0–8px） | SaaS 悬浮阴影卡片（现状未出现，保持不出现） |
| 细分隔线构成列表/表格层级 | 所有内容一律卡片化 |
| 阅读区无边框干扰（正文裸排于画布） | 正文区多卡片嵌套 |

### 3.5 影像与图形

| ✅ | ❌ |
| --- | --- |
| 皇甫谧肖像/古籍书影/史料照片/地域影像为主视觉（需内容资产；客户材料已授权，来源标注） | 无来源的 AI 古风插画 |
| 线条型图标（无衬线图标集，见 UI-01） | 彩色 emoji / 剪贴画 |
| 时间轴、谱系图为线稿风格（细线+节点） | 3D 水晶/渐变装饰 |

### 3.6 动效

- 仅用于状态传达：过渡、加载、聚焦；遵循 `prefers-reduced-motion`（P10）。
- 无弹跳/粒子/滚动放大等装饰动效。

## 4. 标志性视觉瞬间（Signature Moments，Rare UI 适用点）

遵循"小型、有界、点缀"原则（AGENTS.md 选择顺序），仅以下场景允许高表现力：

1. **首页 HERO**：皇甫谧题名 + 一句权威定义 + 身份徽章；允许克制的入场过渡。
2. **《针灸甲乙经》专题入口**：书籍书影式卡片 + 篇章结构预览。
3. **人物页扉页**：姓名、生卒年（215—282）、竖排题名点睛。
4. **时间轴**：线稿时间轴（人生阶段/事件/地点）。
5. **传承谱系图**：线稿关系图。
6. **政校共建署名带**：机构名（完整官方名称，CR-006）谨慎呈现。

其余一律走标准组件。

## 5. 双层面差异化（公众 vs 研究）

| 维度 | 公共门户 | 研究工作台 |
| --- | --- | --- |
| 密度 | 低（叙事优先） | 高（信息优先） |
| 装饰 | 允许策展式留白与点睛 | 零装饰 |
| 字体 | 衬线叙事 + 无衬线 UI | 无衬线为主（效率） |
| 配色 | 暖白画布 + 朱砂强调 | 白画布 + 中性强调 + 语义色 |
| 信息 | 摘要 + 出处可见 | 全字段 + 证据链 |
| 动效 | 克制叙事动效 | 无/极简 |

---

## 6. 暗色模式方向

- 深色画布取"墨黑"而非纯黑（如 `#16130f` 暖黑），文字取暖白。
- 朱砂/铜金在深色上提高明度以保对比（WCAG AA）。
- 深色默认不强制；跟随系统偏好（现有 useTheme 基础），在 UI-01 补齐 token 覆盖后生效。

## 7. 展厅/大屏扩展方向（仅方向，不实施）

- 画布无关：token 支持"放大档位"（间距/字号 scale 整体放大），UI-14 验证。
- 深色画布 token 复用为展陈基底；影像优先布局。
- WebGL/WebXR/720 全景：视觉 token 与视图层解耦；资产字段（来源/授权）已具备，本期只保证"不阻碍"。

## 8. 参考锚点（作为气质校准的公开参照，非抄袭来源）

- 中国哲学书电子化计划（ctext.org）——古籍阅读密度与学术气质。
- 世界数字图书馆 / 各国家图书馆数字馆藏——数字档案策展感。
- 顶级博物馆官网（如大英博物馆、故宫博物院数字文物库）——克制展示与说明牌式信息。
- 学术出版社（商务印书馆/中华书局数字资源）——中文出版排版。
- DH 工具（Voyant、Palladio）——研究端密度与关系可视化。
