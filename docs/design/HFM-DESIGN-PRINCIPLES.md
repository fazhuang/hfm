# HFM 设计原则 — Design Principles

Status: DESIGN INPUT（提案，非治理文档）
Date: 2026-08-31 · 配套文档: HFM-UI-DESIGN-AUDIT / HFM-VISUAL-DIRECTION / HFM-DESIGN-TOKENS-PROPOSAL / HFM-INFORMATION-ARCHITECTURE / HFM-UI-OPTIMIZATION-DAG
适用对象: 本轮 UI 优化全部 WP（UI-01…UI-15）的设计与验收基准。

---

## 0. 产品定义（本原则的事实前提）

> 以**皇甫谧为核心文化 IP**，以**权威数字人文资料**为基础，以**医学本科院校科研教学能力**为支撑，以**地方政府非遗文化传播**为公共出口的数字人文基础设施。

UI 必须同时承担八项职责（对应 CR-003 目标与双层架构 CR-009）：

1. 权威文化展示
2. 数字人文研究
3. 学术资料检索
4. 教学辅助
5. 非遗传播
6. 政校共建成果展示
7. 普通公众低门槛浏览
8. 后续数字展厅 / 大屏 / 沉浸式内容扩展

**排除性定义**：HFM UI 不得被设计成 —— 政府门户网站、学校官网、中医药宣传网站、博物馆静态展板、SaaS 后台、HFB 换皮版。

---

## P1 — CONTENT FIRST（内容优先）

内容是主角。史料、人物、文献、知识关系是平台存在的理由；装饰、动效、品牌元素不得压过内容。

- 布局优先分配空间给正文、证据与导航，而非装饰性视觉。
- 图片/插画必须承载信息（肖像、古籍书影、史料照片、地图），不承载纯装饰。
- 验收：在移除全部装饰层后，平台仍可完成"浏览→检索→阅读→引用"全流程。

## P2 — AUTHORITY（权威性）

首先建立"权威数字人文平台"的可信感，而非商业宣传感。

- 视觉基调：安静、克制、可信，向"学术机构 + 档案馆 + 学术出版"看齐。
- 所有事实展示均带出处意识（来源可见、版本可见、证据可见），不出现无出处的"宣传式断言"。
- 禁止广告化表达：无促销横幅、无弹窗引导、无"爆款"文案。
- 验收：目标用户（研究者/学生/参观者）3 秒内能判断这是"可信的学术资料平台"而非"营销网站"。

## P3 — EASTERN HUMANITIES, NOT PSEUDO-ANCIENT（东方人文，而非伪古风）

允许建立东方人文气质，但禁止：

- ❌ 大面积仿古卷轴 / 陈旧宣纸背景 / 廉价水墨 / 大量祥云回纹 / 金龙宫廷风 / 古装游戏 UI / "中医养生馆"视觉语言。
- ✅ 允许的东方人文表达：留白、克制线条、细边框、墨色层级、印章式/朱砂式低饱和点缀、纵向题名的克制的点睛使用、衬线中文标题。

- 文化符号只做"点睛"（一处、低频、语义明确），不做"铺底"。
- 验收：任何页面截取装饰层后，不出现"古装游戏 / 养生馆"误判。

## P4 — MODERN SCHOLARLY（现代学术）

整体是**现代数字人文设计**，不是复古设计。

- 排版、网格、交互、可访问性遵循当代 Web 标准；古籍气质来自排版与字体，而非材质贴图。
- 推荐核心气质：**克制、典雅、学术、安静、可信、现代**。
- 验收：页面与现代顶尖数字人文项目（如中国哲学书电子化计划、世界数字图书馆、各档案馆数字藏品页）并置时气质同频。

## P5 — CULTURAL IDENTITY（文化识别）

必须具有皇甫谧项目自己的视觉识别，不能成为通用模板。

- 唯一身份色（heritage accent，低饱和朱砂/暗金系，见 Token 提案）贯穿导航、强调、印章式点缀。
- 专属题名排版（竖排题名或印章式徽记可作为品牌资产候选，经 UI-01 验证后定稿）。
- 验收：去掉 logo 文字后，页面配色与排版组合仍可被识别为"皇甫谧平台"（与医院/学校/政府/中医馆模板显著区分）。

## P6 — READING FIRST（阅读优先）

古籍、史料与学术内容必须具备优秀的长文本阅读能力。

- 正文列宽受控（约 34–42em / 中文约 28–40 字/行），行高 ≥1.8，正文 ≥16px。
- 阅读模式支持字号放大（≥120%）、衬线正文、无干扰排版；移动端默认舒适行距。
- 长文不因布局装饰牺牲：正文区域无跳动、无侵入式卡片、无广告位。
- 验收：以《针灸甲乙经》卷一为例，桌面与移动端连续阅读 10 分钟无不适；可无滚动干扰地完成整章阅读。

## P7 — EXPLORATION（可探索）

人物、时间、地点、著作、事件、知识关系之间允许自然探索。

- 每条实体信息（人物/著作/事件/地点/术语）都是可点击入口，指向其详情或相关集合。
- 详情页提供"相关人物 / 相关地点 / 相关著作 / 史料来源"关联区。
- 渐进披露：浅层先给摘要与链接，深层（证据链、版本对校、原始 Citation）逐步展开。
- 验收：从首页任一点开始，最多 3 次点击可到达一条带 Citation 的原文段落，反之亦然（图可达性测试）。

## P8 — EVIDENCE VISIBLE（证据可见）

学术来源、版本、引用、证据不应藏在后台。

- 公共端：人物/著作/段落旁显示"来源、版本、出处"等元数据；正文段落关联 Source/Citation 标识。
- 研究端：Evidence Chain 完整可见（Assertion → Evidence → Source → Citation → Version）。
- 证据标识使用统一语义色与图标（见 Token 提案 Evidence/Citation 语义色），不做隐藏式 footnote。
- 验收：任意公开页面，用户无需登录即可看到内容条目"来自哪个版本 / 哪个来源"。

## P9 — PROGRESSIVE DISCLOSURE（渐进披露）

普通公众看到简单内容；研究者可以逐层深入。

| 层级 | 受众 | 内容 | 界面 |
| --- | --- | --- | --- |
| T1 浏览 | 公众/参观者 | 叙事、摘要、可视化入口 | 低密度、高叙事 |
| T2 探索 | 学生/爱好者 | 列表、元数据、版本信息、原文阅读 | 中密度 |
| T3 研究 | 研究者（登录） | 证据链、版本对校、Citation、Notes、检索面 | 高密度、高可追溯 |

- 层级之间用"了解更多 / 进入研究"类动作自然衔接，不做强制登录墙（公共内容始终可匿名浏览）。
- 验收：T1 用户完成浏览/阅读不需要理解"版本、Citation"等概念；T3 用户不需要穿越叙事层即可直达工具。

## P10 — ACCESSIBILITY（无障碍）

禁止以"传统文化设计"为理由牺牲可用性。

- 对比度：正文与背景 ≥ 4.5:1（WCAG AA），大号文字 ≥ 3:1；muted 色在浅底需 ≥4.5:1 或在非正文场景豁免并记录。
- 字号：正文 ≥16px 可缩放；不锁定 zoom。
- 行距：≥1.5（正文 ≥1.8）；中文字距正常到略松。
- 可点击性：链接/按钮目标 ≥44×44px（触摸）与 ≥24px 可见热区（桌面），焦点状态始终可见。
- 键盘：全流程可键盘操作；skip-link 直达正文；对话框/抽屉焦点圈闭（已有 useFocusTrap 基线）。
- 响应式：断点矩阵不回归（P2-01-AC-05 基线）。
- 动效：所有动效遵循 `prefers-reduced-motion`；动效不承载唯一信息。
- 语义：保留现有 axe 通过基线（P2-01-AC-04），并扩展到全部新页面。
- 验收：axe 全站通过 + 键盘走查清单通过 + 400% 缩放无内容丢失（阅读器尤其）。

## 应用规则（如何用原则把关）

1. **优先级裁决**：P1/P6/P10 为硬约束，任何视觉提案不得以审美为由违反；P2/P4/P8 为气质约束；P3/P5 为方向约束；P7/P9 为信息架构约束。
2. **WP 入口检查**：每个 UI WP 开始前，对照本原则列出其设计假设；验收时逐条对照（见 DAG 中 visual acceptance）。
3. **冲突处理**：原则间冲突时按上述优先级裁决，并在 WP 记录中写明取舍。
4. **不因本原则修改正式 Scope**：本文件是 UI 优化的工作基准，不改变 Phase-2 Scope Register / DAG / Acceptance Contract 的判定。
